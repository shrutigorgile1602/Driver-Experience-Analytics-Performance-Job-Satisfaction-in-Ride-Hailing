# 🚗 Driver Experience Analytics: Performance & Job Satisfaction in Ride-Hailing

## 📌 Project Overview

This project focuses on analyzing driver behavior, earnings patterns, and job satisfaction in the ride-hailing industry using **Power BI and Machine Learning techniques**.

The goal is to identify key factors influencing driver satisfaction and performance, enabling ride-hailing platforms to improve **driver retention, operational efficiency, and service quality**.

---

## 🎯 Objectives

- Analyze driver earnings and ride activity patterns  
- Identify factors affecting job satisfaction  
- Study the impact of working hours and workload  
- Evaluate platform-wise performance (Ola, Uber, Rapido)  
- Build predictive insights using Machine Learning  
- Provide actionable business recommendations  

---

## 📊 Key Performance Indicators (KPIs)

- 👤 Total Drivers  
- 💰 Average Daily Earnings  
- ⭐ Average Satisfaction Score  
- 🚗 Average Rides per Day  
- ⏱ Average Working Hours  

---

## 📈 Power BI Dashboard Features

### 🔹 1. Driver Performance Analysis
- Earnings vs Ride Volume (Scatter Analysis)  
- Earnings vs Working Hours  
- Earnings by Driving Experience  

### 🔹 2. Satisfaction Analysis
- Platform-wise Satisfaction (Uber, Ola, Rapido)  
- Overall Driver Satisfaction KPI  
- Factors affecting satisfaction  

### 🔹 3. Operational Insights
- Ride Demand by Time (Afternoon, Night, Late Night)  
- Location-wise Earnings Analysis  
- Vehicle Type Distribution  

### 🔹 4. Driver Behavior Insights
- Full-time vs Part-time distribution  
- Platform preference analysis  
- Ride frequency patterns  

### 🔹 5. Challenges & Issues
- Biggest challenges faced by drivers  
- App-related issues analysis

## 📊 Key Insights

- Higher ride volume leads to increased earnings  
- Longer working hours do not guarantee higher satisfaction  
- Incentives and app performance significantly impact satisfaction  
- Fuel cost and operational challenges reduce profitability  
- Platform preference varies based on earnings and ride availability  

---

## 🚀 Business Recommendations

- Improve incentive structures to boost satisfaction  
- Optimize ride allocation for balanced workload  
- Enhance app performance and reduce technical issues  
- Focus on high-demand time slots for better earnings  
- Implement driver support systems to reduce challenges
